Integrating Text Files in HTML

Learn different methods to add and display text file content in your web pages

Using JavaScript Fetch API

Dynamically load and display text file content with JavaScript

// Fetch and display text file
fetch('example.txt')
.then(response => response.text())
.then(data => {
  document.getElementById('content').innerText = data;
});

Using HTML Download Link

Create a direct download link for your text files

<a href="example.txt" download>
  Download Text File
</a>

Using File Reader API

Allow users to upload and view text files directly in the browser

const fileInput = document.getElementById('fileInput');
fileInput.addEventListener('change', (e) => {
  const file = e.target.files[0];
  const reader = new FileReader();
  reader.onload = (e) => {
    document.getElementById('content').innerText = e.target.result;
  };
  reader.readAsText(file);
});

Embedding Text with Object Tag

Use the HTML object tag to embed text content directly

<object data="example.txt" type="text/plain" width="100%" height="300">
  <p>Fallback text if the object cannot be displayed.</p>
</object>
